# Code of Conduct

We want a welcoming, technical, low-drama community.

## Expected

- Be respectful and assume good faith.
- Critique ideas with evidence, not people.
- Keep secrets, personal notes and private logs out of issues and PRs.

## Unacceptable

- Harassment, personal attacks, doxxing.
- Posting generated vault content that contains real private data.
- Misrepresenting what the software does.

## Enforcement

Open a private issue to the maintainers. Maintainers may edit or remove
content and ban accounts. Be concise; include only facts.
