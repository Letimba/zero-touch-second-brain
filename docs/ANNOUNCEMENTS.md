I got tired of deciding what to save from agent sessions, so I built a small
loop that does it: clipboard and finished sessions become drafts, a dedicated
agent distills each into at most five atomic lessons, and the next session reads
a ten-rule index instead of the whole vault. It runs locally, uses plain
Markdown, works on Android/Termux, and the agent routing is measured with a
repeatable 11-scenario benchmark (100/100). MIT licensed. Feedback welcome.
