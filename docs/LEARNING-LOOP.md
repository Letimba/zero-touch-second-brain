# Learning loop

## Session start (retrieval)

1. Read only the top-rules table of `_Lernindex.md`.
2. Open a full lesson only if its title or scope matches the task.
3. Apply silently; cite only when it helps.

## Session end (capture)

1. For non-trivial work, run `/session-learn` or
   `bash automation/brain-auto.sh --session-now`.
2. Max five new lessons per session, each under 400 words.
3. Check for duplicates before creating a lesson.
4. No raw chat transcripts, no secrets in curated notes.

## Quality bar

A lesson contains: rule, why, application, limits, related links, priority and
confirmation date. A protocol is at most 300 words and links its lessons.

## Known gap

Redaction covers token-shaped strings only. Generated digests can still contain
project names and local paths — keep them out of public repositories.
